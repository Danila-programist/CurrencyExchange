# Тесты для Currency Exchange API

Этот каталог содержит тесты для приложения обмена валют, написанные с использованием pytest.

## Структура тестов

### Основные тестовые файлы:

- **`test_main.py`** - Простые тесты для основного приложения
- **`test_main_app.py`** - Расширенные тесты для FastAPI приложения
- **`test_config.py`** - Тесты для конфигурации приложения
- **`test_currency_utils.py`** - Тесты для утилит конвертации валют
- **`test_currency_schemas.py`** - Тесты для Pydantic схем валют
- **`test_hashing_utils.py`** - Тесты для утилит хэширования паролей
- **`conftest.py`** - Общие фикстуры для всех тестов

## Запуск тестов

```bash
# Запуск всех тестов
pytest tests/

# Запуск с подробным выводом
pytest tests/ -v

# Запуск конкретного файла тестов
pytest tests/test_currency_utils.py

# Запуск конкретного теста
pytest tests/test_currency_utils.py::TestConvertRates::test_convert_rates_single_currency
```

## Покрытие тестами

Созданные тесты покрывают:

1. **Утилиты конвертации валют** - основная бизнес-логика
2. **Утилиты хэширования** - безопасность паролей
3. **Pydantic схемы** - валидация данных
4. **Конфигурация** - настройки приложения
5. **Основное приложение** - FastAPI приложение

## Фикстуры

В `conftest.py` определены общие фикстуры:
- `test_env_vars` - тестовые переменные окружения
- `sample_currency_rates` - примерные курсы валют
- `sample_currency_data` - примерные данные валюты
- `sample_conversion_data` - примерные данные конвертации
- `mock_external_api_response` - мок-ответ внешнего API
- `test_passwords` - тестовые пароли

## Примечания

- Тесты используют моки для изоляции от внешних зависимостей
- Переменные окружения мокаются для тестирования конфигурации
- Тесты проверяют как успешные, так и ошибочные сценарии
