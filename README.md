## Введение

Разработка проекта на FastAPI, который служит простым приложением для обмена валют. Пользователи могут получать последние курсы обмена валют и выполнять их конвертацию, а также смотреть список доступных валют. Для использования проекта реализована аутентификация JWT для доступа пользователей с СУБД PostgreSQL, а также интеграция с открытым API обменных курсов для получения данных об обменных курсах в режиме реального времени.

## Технологический стэк

Для выполнения проекта используются следующие компоненты разработки:

- Python 3.12
- Docker/Docker-compose
- Alembic 
- Poetry
- external APIs
- Makefile
- SQLAlchemy
- PostgreSQL/asyncpg
- Redis
- Limiter
- PyJWT
- Pytest
- Pydantic
- Pydantic-settings
- Asyncio
- Uvicorn
- RBAC
- logging
- aiohttp


## Функциональность

1. Список доступных валют
2. Конвертация из базовой валюты в остальные валюты
3. История валют
