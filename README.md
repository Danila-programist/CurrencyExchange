## Введение

Разработка проекта на FastAPI, который служит простым приложением для обмена валют. Пользователи могут получать последние курсы обмена валют и выполнять их конвертацию, а также смотреть список доступных валют. Для использования проекта реализована аутентификация JWT для доступа пользователей с СУБД PostgreSQL, а также интеграция с открытым API обменных курсов для получения данных об обменных курсах в режиме реального времени или через администратора.

## Функциональность

1. Список доступных валют с дополнительной информацией 


**Endpoint:**  
`GET /api/v1/currency/all`

**Пояснения к полям ответа:**

Получаем JSON-ответ в виде списка валют с ключом - код валюты, а также значений в виде 
словарей со следующей информацией:

- symbol - сивмол валюты
- name - название валюты на английском языке
- symbol_native - символ или обозначение валюты в стране происхождения
- decimal_digits - количество знаков после запятой для валюты
- rounding - правило округления
- code - код валюты
- name_plural - название валюты во множественном числе
- type - тип валюты
- countries - список стран, где используется валюта


2. Конвертация из базовой валюты

**Endpoint:**  
`GET /api/v1/currency/convert`

Принимает также три необязательных query-параметра:
- from_currency (по умолчанию USD) необходим для реализации базовой валюты, от которой будет получить информацию по остальным валютам
- to_currency (по умолчанию все валюты) необходим для получения конкретной валюты 
- amount (по умолчанию 1) необходим для количества переведенной валюты to_currency 

Получаем JSON-ответ в виде списка валют или одной валюты со следующей информацией:

- from_currency - исходная валюта
- to_currency - необходимая валюта
- rate - отношение исходной валюты к необходимой
- amount - количество необходимой валюты
- converted_amount - произведение rate на amount

3. Регистрация пользователя

**Endpoint:**  
`POST /api/v1/users/register`

Передаются пароль и логин для нового пользователя, а если в базе данных находится пользователь с этим никнеймом, то выдается ошибка

Принимает два обязательных параметра:
- username - никнейм пользователя
- password - желаемый пароль

4. Логирование пользователя

**Endpoint:**  
`POST /api/v1/users/login`

Передаются пароль и логин для пользователя, если такой пользователь существует в базе данных и пароли совпадают, то в таком случае
создается jwt-токен для обращения к ручкам основной функциональности

Принимает два обязательных параметра:
- username - никнейм пользователя
- password - пароль

5. Ограниченное количество запросов в минуту к эндпоинтам в зависимости от роли клиента. Для админа - 10 запросов, пользователь - 3, а гостю 1 запрос в минуту. 

6. Ограничение к доступу к эндпоинтам. Для `GET /api/v1/currency/all` общедоступно, а для `GET /api/v1/currency/convert` только авторизованным пользователям.

7. Простой запуск локально через docker-compose с минимальной настройкой приложения.

## Локальный запуск 

Необходимо, чтобы были установлены следующие компоненты:

- `Docker` и `docker-compose`
- `Python 3.12`
- `Poetry`

### Установка

1. Создание виртуального окружения и установка зависимостей
```commandline
poetry install
```

2. Активация виртуального окружения

```commandline
make init_env
```

3. Копирование в файл .env

```commandline
make env_file
```
